# Email signature icons

White glyphs on transparent backgrounds, 96x96 PNG, for the Pulse Tools Email Signature Builder.
The builder places each icon inside a table cell with a bgcolor, so one icon set works for every color style.

Served via jsDelivr:
https://cdn.jsdelivr.net/gh/ldecarmine/assets@main/email-icons/<name>.png

Files: linkedin, x, github, youtube, instagram, facebook, whatsapp, calendar (.png), spacer.gif (1x1 transparent).

Icons: Font Awesome Free (https://fontawesome.com), licensed CC BY 4.0.
